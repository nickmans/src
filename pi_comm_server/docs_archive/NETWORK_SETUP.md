# Network Setup for STM32 Nucleo H755ZI ↔ Raspberry Pi 5

## Overview
Direct Ethernet connection between Nucleo H755ZI and Raspberry Pi 5 using static IP addresses.

---

## Raspberry Pi 5 Configuration

### 1. Find Ethernet Interface Name
```bash
ip link show
```
Look for the Ethernet interface (e.g., `eth0`, `enp1s0`, or `end0`)

### 2. Set Static IP Using NetworkManager
```bash
# Set static IP (replace eth0 with your interface name)
sudo nmcli con mod "Wired connection 1" ipv4.addresses 192.168.1.100/24
sudo nmcli con mod "Wired connection 1" ipv4.method manual
sudo nmcli con down "Wired connection 1"
sudo nmcli con up "Wired connection 1"
```

### 3. Verify Configuration
```bash
ip addr show eth0
# Should show: inet 192.168.1.100/24

ping 192.168.1.10
# Wait until STM32 is configured, then this should work
```

### 4. Alternative: Using `/etc/network/interfaces` (Debian/Ubuntu)
```bash
sudo nano /etc/network/interfaces
```

Add:
```
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
```

Restart networking:
```bash
sudo systemctl restart networking
```

### 5. Firewall (if needed)
```bash
# Allow TCP port 9000
sudo ufw allow 9000/tcp

# Or disable firewall for testing
sudo ufw disable
```

## STM32 Nucleo H755ZI Configuration

### 1. Hardware Setup
- Connect Ethernet cable directly between Nucleo and Pi5
- Power both devices
- No router/switch needed for direct connection

### 2. STM32CubeMX/IDE Configuration

**LwIP Settings:**
```c
// In lwipopts.h or CubeMX configuration
#define LWIP_DHCP              0     // Disable DHCP
#define LWIP_TCP               1
#define LWIP_NETCONN           1     // Or use sockets
#define LWIP_SOCKET            1

// Static IP configuration
#define IP_ADDR0   192
#define IP_ADDR1   168
#define IP_ADDR2   1
#define IP_ADDR3   10

#define NETMASK_ADDR0   255
#define NETMASK_ADDR1   255
#define NETMASK_ADDR2   255
#define NETMASK_ADDR3   0

#define GW_ADDR0   192
#define GW_ADDR1   168
#define GW_ADDR2   1
#define GW_ADDR3   1  // Not used for direct connection
```

**In main.c:**
```c
// Initialize LwIP with static IP
ip_addr_t ipaddr, netmask, gw;

IP4_ADDR(&ipaddr,  192, 168, 1, 10);
IP4_ADDR(&netmask, 255, 255, 255, 0);
IP4_ADDR(&gw,      192, 168, 1, 1);

MX_LWIP_Init();  // Generated by CubeMX
```

### 3. Verify Link Status
```c
// Check Ethernet link
if (netif_is_link_up(&gnetif)) {
    printf("Ethernet link UP\r\n");
} else {
    printf("Ethernet link DOWN - check cable\r\n");
}
```

## Network Testing

### From Pi5:
```bash
# 1. Check if STM32 is reachable
ping 192.168.1.10

# 2. Check if TCP port is listening (after STM32 client starts)
nc -zv 192.168.1.100 9000

# 3. Monitor network traffic
sudo tcpdump -i eth0 -n host 192.168.1.10
```

### From STM32:
```c
// Try connecting to Pi5
int sock = socket(AF_INET, SOCK_STREAM, 0);
struct sockaddr_in server;
server.sin_family = AF_INET;
server.sin_port = htons(9000);
inet_pton(AF_INET, "192.168.1.100", &server.sin_addr);

if (connect(sock, (struct sockaddr*)&server, sizeof(server)) == 0) {
    printf("Connected to Pi5!\r\n");
} else {
    printf("Connection failed: %d\r\n", errno);
}
```

## Common Issues & Solutions

### Issue 1: "Network is unreachable"
**Cause:** IP addresses not in same subnet  
**Solution:** Verify both devices use `192.168.1.x/24`

### Issue 2: "No route to host"
**Cause:** Firewall blocking or wrong interface  
**Solution:** 
```bash
sudo ufw disable
sudo iptables -F
```

### Issue 3: Ethernet link down
**Cause:** Cable not connected or wrong cable type  
**Solution:** 
- Use Ethernet cable (Cat5e or better)
- Check LED indicators on RJ45 ports
- Try different cable

### Issue 4: Pi5 DHCP conflicts
**Cause:** NetworkManager trying to get DHCP on Ethernet  
**Solution:** Explicitly set `ipv4.method manual` (see Pi5 setup above)

### Issue 5: STM32 not getting IP
**Cause:** LwIP not initialized or DHCP enabled  
**Solution:** 
- Verify `LWIP_DHCP = 0` in lwipopts.h
- Check `MX_LWIP_Init()` is called
- Call `MX_LWIP_Process()` in main loop or RTOS task

## Quick Verification Script (Pi5)

Save as `test_network.sh`:
```bash
#!/bin/bash

echo "=== Network Setup Verification ==="

# Check interface
echo -e "\n1. Ethernet Interface:"
ip addr show eth0 | grep "inet "

# Check if IP is correct
echo -e "\n2. Pi5 IP Address:"
ip -4 addr show eth0 | grep -Po 'inet \K[\d.]+'

# Ping STM32
echo -e "\n3. Ping STM32 (192.168.1.10):"
timeout 2 ping -c 1 192.168.1.10 && echo "✓ STM32 reachable" || echo "✗ STM32 not reachable"

# Check server status
echo -e "\n4. TCP Server Status:"
sudo systemctl status omni_tcp_server | grep "Active"

# Check port
echo -e "\n5. Port 9000 Status:"
sudo netstat -tuln | grep ":9000"

echo -e "\n=== Done ==="
```

Run:
```bash
chmod +x test_network.sh
./test_network.sh
```

## Auto-crossover Note
Modern Ethernet devices (including Pi5 and Nucleo H755ZI) support **Auto-MDI/MDI-X**, so you can use a regular straight-through Ethernet cable. No crossover cable needed.
